# PREMIUM VISUAL + GSAP MOTION + SMOOTH INTERACTIONS + FUNCTIONAL UX

You are working on the existing VIREON Library web application.

Your objective is to elevate the existing application into a polished, premium, production-quality SaaS experience while preserving the existing architecture and functionality.

This phase focuses ONLY on:

1. Visual refinement
2. GSAP + ScrollTrigger motion
3. Smooth scrolling and micro-interactions
4. Button/card interactions
5. Functional UX audit
6. Responsive and accessibility polish
7. Performance-safe animation implementation

DO NOT rewrite unrelated systems.

DO NOT change the product's core architecture.

## 7. GSAP + SCROLLTRIGGER
==================================================

Use GSAP and ScrollTrigger for meaningful motion.

If GSAP is already installed, reuse the existing version.

If GSAP is not installed, add it only if it provides meaningful value.

Do NOT introduce GSAP merely because this prompt mentions GSAP.

Use GSAP primarily for:

- Scroll-driven animations
- Section reveals
- Staggered card entrances
- Parallax
- Coordinated multi-element timelines
- Magnetic button interactions
- Scroll progress

The animation language must feel:

- Smooth
- Controlled
- Subtle
- Premium
- Intentional

Avoid:

- Excessive bouncing
- Aggressive scaling
- Flashy transitions
- Constant movement
- Large rotations
- Distracting effects

==================================================
## 8. EXISTING ANIMATION SYSTEM
==================================================

If Framer Motion already handles a simple animation effectively:

KEEP IT.

Do not rewrite every existing animation just to use GSAP.

Use GSAP where it has clear advantages.

Avoid having multiple animation systems fighting over the same element.

Do not create unnecessary animation abstractions.

Prefer a clean architecture such as:

- Reusable reveal utilities
- Reusable stagger patterns
- Reusable magnetic interaction
- Component-level GSAP contexts

Use gsap.context() where appropriate in React.

Clean up GSAP contexts and ScrollTriggers when components unmount.

==================================================
## 9. SECTION REVEALS
==================================================

Add scroll-triggered reveals to major sections.

Preferred motion:

opacity:
0 → 1

transform:
translateY(20–40px) → 0

Use subtle stagger for groups of cards.

Suggested stagger:

0.06–0.12 seconds

Do not make sections fly across the screen.

Animations should feel almost invisible when not paying attention, but noticeably improve the overall polish.

==================================================

- Hover

- Focus

- Loading states

Use subtle:

- Transform

- Smooth response

## 18. PERFORMANCE
==================================================

Animations must not destroy performance.

Prefer GPU-friendly properties:

- transform
- opacity

Avoid expensive layout animation where transform can achieve the same effect.

Avoid unnecessary:

- width animation
- height animation
- top/left animation
- layout thrashing

Avoid excessive ScrollTrigger instances.

Avoid unnecessary React re-renders.

Avoid memory leaks.

Clean up animation contexts correctly.
