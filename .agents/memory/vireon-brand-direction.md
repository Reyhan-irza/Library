# Vireon brand direction

Vireon should present as an independent digital reading workspace, never as a school-specific system. Motion should communicate depth and scroll position through restrained layered movement rather than repeated generic float/fade effects. Copy can be youthful and conversational in marketing surfaces while remaining clear in task-oriented UI. REYHAN IRZA is the developer identity and should remain visible in the public-facing experience. Public-facing mobile navigation can use a dark, immersive full-screen overlay with restrained emerald accents, while the authenticated admin shell uses a compact bottom navigation and bottom-sheet menu on mobile; desktop keeps a structured editorial sidebar.

**Why:** The product was rebranded away from its original school identity and the user explicitly wants a premium, distinctive SaaS feel rather than generic AI-generated polish. The user chose bottom navigation for the admin dashboard because it is easier to reach on mobile, while public-facing surfaces have a separate approved menu direction.

**How to apply:** When adding or redesigning landing, login, or public-facing surfaces, scan all source, metadata, artifact labels, previews, and schema comments for school-specific identity; preserve reduced-motion fallbacks, the neutral Vireon voice, and the public mobile overlay. For authenticated admin pages, preserve the bottom mobile navigation, bottom-sheet secondary menu, and desktop workspace sidebar unless the user explicitly requests a redesign.
