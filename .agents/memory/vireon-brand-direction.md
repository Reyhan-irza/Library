# Vireon brand direction

Vireon should present as an independent digital reading workspace, never as a school-specific system. Motion should communicate depth and scroll position through restrained layered movement rather than repeated generic float/fade effects. Copy can be youthful and conversational in marketing surfaces while remaining clear in task-oriented UI. REYHAN IRZA is the developer identity and should remain visible in the public-facing experience. The approved mobile navigation direction is a dark, immersive full-screen overlay with restrained emerald accents, numbered editorial links, and a morphing menu mark.

**Why:** The product was rebranded away from its original school identity and the user explicitly wants a premium, distinctive SaaS feel rather than generic AI-generated polish. The user reviewed this mobile-menu direction and confirmed it should be kept.

**How to apply:** When adding or redesigning landing, login, or public-facing surfaces, scan all source, metadata, artifact labels, previews, and schema comments for school-specific identity; preserve reduced-motion fallbacks, the neutral Vireon voice, and the approved mobile navigation unless the user explicitly requests a redesign.
